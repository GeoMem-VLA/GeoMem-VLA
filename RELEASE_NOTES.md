# Release notes

This source release offers a basic LIBERO workflow and a secondary RoboTwin
adapter. It retains general StarVLA modules and upstream attribution.

Public defaults use single-machine ZeRO-2, explicit external paths, matched
batch/group/memory settings, streaming evaluation, and disabled remote logging.
The short training and one-task evaluation examples are workflow checks, not
benchmark reproduction recipes or validated performance claims.

Checkpoints, datasets, simulator installations, credentials, local environment
settings, logs, and generated outputs are excluded. Astribot and AgileX example
directories are not included. The parent research workspace is unchanged.
